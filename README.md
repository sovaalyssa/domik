# Дом, в котором всё хорошо

Игра для Анечки, проект «113 дней рождения».

## Публикация через GitHub Pages

1. Распакуй архив.
2. Загрузи его содержимое в корень репозитория: index.html, style.css, game.js и .nojekyll.
3. В Settings → Pages выбери Deploy from a branch, ветку main и папку / (root).
4. Нажми Save. Готовая ссылка появится в том же разделе.

index.html должен находиться прямо в корне репозитория, без дополнительной папки.

Игра работает без установки зависимостей и без подключения к ChatGPT. Ссылку GitHub Pages можно отправить Анечке.

## Управление

На телефоне: кнопки под полем.
На компьютере: стрелки для перемещения и поворота, пробел — положить блок, P — пауза.

Собери шесть полных рядов. После победы появляется треугольная крыша и пожелание.
